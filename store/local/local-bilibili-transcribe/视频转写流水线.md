
## 转写流程

```bash
python -m pip install faster-whisper imageio-ffmpeg nvidia-cublas-cu12 nvidia-cudnn-cu12 \
  -i https://pypi.tuna.tsinghua.edu.cn/simple

# 1. 下载 durl[0].url（Header: Referer: https://www.bilibili.com/）
# 2. 抽音轨（imageio-ffmpeg 自带 ffmpeg）
ffmpeg -y -i in.mp4 -vn -ac 1 -ar 16000 out.wav -loglevel error

# 3. faster-whisper 转写：device=cuda/float16，失败回退 cpu/int8
#    WhisperModel(<本地模型目录>, local_files_only=True)
#    中文技术视频建议带 initial_prompt（术语表）+ vad_filter + condition_on_previous_text=False
```

## CUDA DLL 预加载（可直抄）

```python
# 前提：先装 nvidia-cublas-cu12 + nvidia-cudnn-cu12，否则预加载也找不到 DLL。
# os.add_dll_directory 单独用无效，必须逐个 ctypes.WinDLL(绝对路径) 预加载 + 插 PATH。
import ctypes, glob, os, site
bins = [d for sp in site.getsitepackages() for d in glob.glob(os.path.join(sp, "nvidia", "*", "bin"))]
os.environ["PATH"] = ";".join(bins) + ";" + os.environ["PATH"]
for b in bins: os.add_dll_directory(b)
for f in [x for b in bins for x in glob.glob(os.path.join(b, "*.dll"))]: ctypes.WinDLL(f)
```
