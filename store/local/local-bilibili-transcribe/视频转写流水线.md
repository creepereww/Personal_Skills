# B站视频转文字流水线（无需登录）

> 适用：B站字幕接口需登录（`need_login_subtitle=true`），匿名拿不到字幕时的替代方案。
> 实测：31min 视频，RTX 5070 + whisper-medium，转写约 4 分钟（≈8x 实时）；
> 7:35 视频同环境转写仅 18s（72 段）——短音频很快，瓶颈在装依赖和下模型。
> 已固化为 skill `bilibili-transcribe`（`~/.workbuddy/skills/`），带 `scripts/bili_transcribe.py` 一条龙脚本。
> **本文件只保留匿名 API 端点与模型文件清单；踩坑与用法以 `SKILL.md` 为准，不在此重复维护。**

## 匿名可取的数据

```bash
# 视频信息（标题/简介/cid）
curl "https://api.bilibili.com/x/web-interface/view?bvid=<BVID>"

# 播放器信息：view_points 官方章节 + 章节封面图 URL（目录总览页信息量最大）
curl "https://api.bilibili.com/x/player/v2?bvid=<BVID>&cid=<CID>"

# 章节封面帧（<秒>=view_points 的 from 值）
http://i0.hdslb.com/bfs/vchapter/<CID>_<秒>.jpg

# 播放地址（360P mp4，无需登录）
curl "https://api.bilibili.com/x/player/playurl?bvid=<BVID>&cid=<CID>&qn=32&type=mp4&platform=html5"
```

## 转写流程

```bash
python -m pip install faster-whisper imageio-ffmpeg nvidia-cublas-cu12 nvidia-cudnn-cu12 \
  -i https://pypi.tuna.tsinghua.edu.cn/simple

# 1. 下载 durl[0].url（Header: Referer: https://www.bilibili.com/）
# 2. 抽音轨（imageio-ffmpeg 自带 ffmpeg）
ffmpeg -y -i in.mp4 -vn -ac 1 -ar 16000 out.wav -loglevel error

# 3. faster-whisper 转写：device=cuda/float16，失败回退 cpu/int8
#    WhisperModel(<本地模型目录>, local_files_only=True)
#    中文技术视频建议带 initial_prompt（术语表）+ vad_filter + condition_on_previous_text=False
```

## 环境坑（Windows + RTX 5070 实测）

> 完整坑清单见 `SKILL.md`，此处只留可直抄的代码 + 一条重要修正。

```python
# ctranslate2 报 "cublas64_12.dll is not found"（脚本里 preload_cuda_dlls() 已实现）：
#   前提是先装 nvidia-cublas-cu12 + nvidia-cudnn-cu12，否则预加载也找不到 DLL。
#   os.add_dll_directory 单独用无效，必须逐个 ctypes.WinDLL(绝对路径) 预加载 + 插 PATH。
import ctypes, glob, os, site
bins = [d for sp in site.getsitepackages() for d in glob.glob(os.path.join(sp, "nvidia", "*", "bin"))]
os.environ["PATH"] = ";".join(bins) + ";" + os.environ["PATH"]
for b in bins: os.add_dll_directory(b)
for f in [x for b in bins for x in glob.glob(os.path.join(b, "*.dll"))]: ctypes.WinDLL(f)
```

```text
⚠️ 修正（2026-09-14 实测，旧描述"Bash 工具实为 cmd"是错的）：
Bash 工具实为**残缺的 Git Bash**，不是 cmd：
  - 确实没有 ls / mkdir / tail / head / dirname（command not found）
  - 但**多行 python -c "带换行的字符串" 可以正常执行**（实测建目录/下载/列文件均成功）
    → 不必一律写成 .py 脚本文件，多行 python -c 更快
  - 管道给 tail/head 会 SIGTERM 掉整条命令 → 别用管道
  - 启动时 shell-runtime-bash-env.sh 自身报 "dirname: command not found"，可忽略
  - 仍别在命令里写 %TEMP%（展开行为不确定）→ 用 python 的 os.environ 取路径

PowerShell 工具输出经常不回显 → 验证文件落盘改用 python 列目录。
```
