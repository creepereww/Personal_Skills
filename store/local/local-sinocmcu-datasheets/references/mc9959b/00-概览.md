# MC9959B 产品概要（第 1 章，p.4–9）

> 源：MC9959B 用户手册 V1.0.1 · 页码为 PDF 页序

## 1.1 产品特性（p.4–5）

- **8 位 CPU 内核**
  - 精简指令集，8 级深度硬件堆栈
  - CPU 为双时钟，可在系统高/低频时钟之间切换
  - 系统高频时钟下 FCPU 可配置为 FHOSC 的 **4/8/16/32/64** 分频（注意：无 2 分频）
  - 系统低频时钟下 FCPU 固定为 FLOSC 的 2 分频
- **程序存储器**
  - 4K×16 位 FLASH 型，可通过间接寻址读取
  - 支持在板**带电**烧录编程，擦写次数至少 **1 万次**
- **数据存储器**
  - 256 字节 SRAM，支持直接/间接寻址
  - **128 字节 EEPROM**，支持单独烧录和软件读写，擦写至少 **1 万次**
- **3 组共 18 个 I/O**
  - P0（P00~P07）、P1（P10~P17）、P2（P20~P21）
  - 所有端口支持施密特输入 + 推挽输出
  - P17 可复用为外部复位 RST 输入
  - 所有端口内置上拉/下拉电阻，可单独使能
  - P20/P21 可复用为外部中断输入，支持外部中断唤醒
  - **所有端口**均支持键盘中断唤醒，可单独使能
- **系统时钟源**
  - 内置高频 RC 振荡器（**32MHz**，无 2MHz 档）
  - 内置低频 RC 振荡器（32KHz）
  - **无外部晶体振荡器支持**
- **系统工作模式**
  - 高速模式：CPU 跑高频时钟，低频时钟源工作
  - 低速模式：CPU 跑低频时钟，高频时钟源可选停止或工作
  - HOLD 模式：CPU 暂停，高频停、低频工作
  - 休眠模式：CPU 暂停，高/低频全停
- **内部自振式看门狗 WDT**：溢出 16ms/64ms/256ms/1024ms；可配始终开/始终关/低功耗关闭
- **4 个定时器**
  - 8 位 T0：外部计数 + BUZ
  - 16 位 T1：外部计数 + BUZ + 内/外部信号输入捕捉
  - 8 位 T2：**PWM（无死区互补）**
  - 8 位 T3：**3 路共周期独立占空比 PWM（无死区互补）**
- **1 个 12 位 SAR ADC**
  - 14 路外部通道 AN0~AN13；2 路内部通道 **GND、VDD**
  - 参考电压可选：**VDD、内部 VIR（2V）** —— 无外部参考
  - ADC 时钟：FCPU 的 2/4/8/16 分频
  - 支持零点校准
- **1 个模拟比较器 CMP**（**负端输入增加 1、1/2 分压**）
  - 共模 0~（VDD-1.4V），支持失调自消除调校（±2mV），输出无回滞且支持去抖
  - 正端可选外部输入或 VDD 内部分压；负端可选外部输入
  - 输出端可选上升/下降沿触发中断，可从端口输出并支持取反
- **中断**
  - 外部 INT0~INT1；键盘中断（**所有 IO**）
  - 定时器 T0~T3、T1 捕捉
  - ADC、CMP、**LVD（支持唤醒）**
  - **无 OPA 中断**（本型号无 OPA 模块）
- **LVD**：2.0/2.2/2.4/2.6/2.8/3.2/3.6/4.0V
- **LVR**：1.8/2.0/2.4/2.7/3.0/3.2V
- **工作电压（@HIRC）**
  - VLVR24 ~ 5.5V @ Fcpu 0~8MHz
  - VLVR20 ~ 5.5V @ Fcpu 0~4MHz
  - VLVR18 ~ 5.5V @ Fcpu 0~2MHz
  - （无 16MHz / VLVR32 档）
- **封装**：QFN20 / QFN16 / MSOP10

## 1.5 端口说明（p.8–9）

| 端口名称 | 类型 | 功能说明 |
|---|---|---|
| VDD | P | 电源 |
| GND | P | 地 |
| P0, P1, P2 | D | GPIO（推挽输出），内部上/下拉 |
| INT0~INT1 | DI | 外部中断输入 |
| TC0~TC1 | DI | 定时器 T0~T1 的外部计数输入 |
| BUZ0 | DO | 定时器 T0 的 BUZ 输出 |
| BUZ1 | DO | 定时器 T1 的 BUZ 输出 |
| PWM2 | DO | 定时器 T2 的 PWM 输出 |
| PWM3A~PWM3C | DO | 定时器 T3 的 3 路 PWM 输出 |
| AN0~AN13 | AI | ADC 外部输入通道 |
| CMPP | AI | CMP 正端外部输入 |
| CMPN0~CMPN3 | AI | CMP 负端外部输入通道 |
| CMPO | DO | CMP 输出 |
| RST | DI | 外部复位输入 |
| PCK0/PDT0, PCK1/PDT1 | D | 编程时钟/数据接口；在线仿真接口 |

**类型码**：P-电源；D-数字（DI 输入 / DO 输出）；A-模拟（AI 输入 / AO 输出）。

> 与 MC9959 相比缺：`VERI`（外部参考输入）、`OPAP/OPAN/OPAO`（运放）、`FPWM2/FPWM3A`（互补 PWM）。
