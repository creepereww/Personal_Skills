# MC9959B 中断（第 13 章，p.59–63）

> 源：MC9959B 用户手册 V1.0.1。位表由版面还原，列位已用 PyMuPDF 校验。

## 中断源一览（p.59）

外部 INT0~INT1、定时器 T0~T3、T1 捕捉、ADC、CMP、LVD（**支持唤醒**）、键盘中断（**最多 18 路**）。
**中断总使能 GIE** 可屏蔽所有。

> 本型号**无 OPA 中断**（芯片本身没有 OPA 模块）。

### 响应过程

1. 响应时硬件把**当前指令的下一条地址**压栈，并**自动清 0 GIE**；不中止当前指令，执行完再跳转。
2. 跳到**中断入口 `0008H`**；ISR 应先保存 **A** 与 **PFLAG**。
3. 处理完恢复 A/PFLAG，用 **`RETIE`** 返回 —— 硬件自动置 GIE=1 并弹栈恢复 PC。

> 注：用外部中断或键盘中断前，必须先把对应端口设为**输入**。

## 触发条件

| 中断 | 触发 | 标志 | 使能 |
|---|---|---|---|
| 外部 INT0/INT1（13.1） | 上升/下降沿、电平变化可选 | INTnIF | INTnIE |
| 定时器 T0~T3（13.2） | 计数溢出 | TnIF | TnIE |
| T1 捕捉（13.3） | 输入捕捉完成 | T1CIF | T1CIE |
| 键盘（13.4） | 最多 18 路端口电平变化 | KBIF | KBIE |
| ADC（13.5） | AD 转换完成 | ADIF | ADIE |
| CMP（13.6） | 比较器输出上升/下降沿 | CMPIF | CMPIE |
| LVD（13.7） | VDD 降至阈值以下（**可唤醒**） | LVDIF | LVDIE |

### P2KBCR — P2 键盘中断控制（p.60）

| Bit | 7 | 6 | 5 | 4 | 3 | 2 | 1 | 0 |
|---|---|---|---|---|---|---|---|---|
| 名称 | - | - | - | - | - | - | P21KE | P20KE |
| R/W | - | - | - | - | - | - | R/W | R/W |
| 初始值 | - | - | - | - | - | - | 0 | 0 |

> 与 9959 差异：9959 只有 P1 支持键盘中断（仅 `P1KBCR`）；9959B 支持**全端口**，新增 `P0KBCR`、`P2KBCR`。
