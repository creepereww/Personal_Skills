## MC9959B 高频参数速查

| 项 | 值 |
|---|---|
| 内核 | 8 位 RISC，单周期指令，硬件堆栈 **8 级** |
| 程序存储器 | **4K×16 位 FLASH**，支持**在板带电烧录**，擦写 ≥**1 万次** |
| 数据存储器 | SRAM **256 字节** + EEPROM **128 字节**（擦写 1 万次，写 8ms） |
| I/O | **18 个**：P0（P00–P07）、P1（P10–P17）、P2（P20–P21） |
| 工作电压 | @8MHz：VLVR24~5.5V；@4MHz：VLVR20~5.5V；@2MHz：VLVR18~5.5V（**无 16MHz 档**） |
| 极限参数 | VDD −0.3~6.0V；Ta −40~85℃；Tstg −65~150℃ |
| 主频 | **仅内部 HIRC 32MHz + LIRC 32KHz**，无外接晶振、无高频微调 |
| ADC | **12 位 SAR**，14 路外部（AN0–AN13）+ GND、VDD；参考 **VDD 或内部 2V**（无外部参考）；**内部增益 ×1/×0.75/×0.5/×0.25** |
| ADC 时钟上限 | 参考 VDD 时 **2MHz**；参考内部 2V 时 **1MHz** |
| 定时器 | T0（8 位）、T1（16 位，带捕捉）、T2（8 位 PWM）、T3（8 位 3 路 PWM）—— **均无死区互补** |
| 模拟 | 1 路 CMP（负端支持 1/2 分压）；**无 OPA** |
| 低功耗 | HOLD 3μA；休眠 1~37μA（视 WDT/LVR 开关） |
| 中断入口 | **0008H**（返回用 `RETIE`）；LVD 中断**可唤醒**；键盘中断**全端口** |
| SFR 起始 | **180H**（000H–0FFH 通用 RAM） |
| 封装 | **QFN20 / QFN16 / MSOP10**（均 3×3×0.75） |

## 检索协议（怎么用最省）

1. **先看上面的速查表** —— 电压/容量/引脚/封装这类问题到这里就答完。
2. **参数类** → `01-电气特性.md`（全表格化，含条件列与 ADC 源阻抗表）。
3. **寄存器怎么配** → 按名字 grep：
   ```bash
   grep -n "ADCR1\|AFCR" references/mc9959b/06-ADC.md
   grep -n "T3CR"       references/mc9959b/05-定时器.md
   grep -n "P0KBCR"     references/mc9959b/10-中断.md
   ```
4. **`05-定时器.md` 有 24K 字符，别整篇读** —— grep 寄存器名或章节号（7.2/7.4/7.5），
   只读命中段前后 30 行。
5. **图类内容**（引脚图、特性曲线、封装尺寸、系统框图）文本里没有，直接告诉用户"见 PDF 第 N 页"，
   **不要凭记忆编尺寸或引脚位置**。
6. 引用数值带页码（文件里有 `<!-- p.N -->` 锚点），方便核对。

## 与 MC9959（旧型号）的关键差异

项目里可能有存量 9959 板子，混用时按此表区分（原始出处：《MC9959 和 MC9959B 差异说明》）：

| 功能 | MC9959（旧） | MC9959B（新） |
|---|---|---|
| OPA | 有整章（`OPACR0/1/CLR`） | **无** |
| 外部晶振 | 支持 32768/455K/4M/8M/16M | **不支持**，仅内部 RC |
| HIRC 频率 | 32MHz / 2MHz 可切，可微调（`HIRCCAL`） | **固定 32MHz**，无微调 |
| FCPU 分频 | 2/4/8/16/32/64 | **4/8/16/32/64**（无 /2） |
| EEPROM | 256B，10 万次，写 5ms | **128B，1 万次，写 8ms** |
| 烧录 | 在板**不带电** | 在板**带电**，端口可由 `DBGCR/DBGPR` 切换 |
| ADC 参考 | VDD、内部 2/3/4V、外部 VER | **VDD、内部 2V**（无外部） |
| ADC 增益 | 无 | **×1/×0.75/×0.5/×0.25**（`AFCR`） |
| ADC 的 VDD 通道 | `VDD/4`（ADCHS=1110） | `VDD` + 固定 1/4 增益（读数等价，不用改代码） |
| ADC 时钟上限 | 统一 1MHz | 参考 VDD 时 **2MHz** |
| PWM 死区 | T2、T3 支持 8+3 互补死区 | **全部取消** |
| 键盘中断 | 仅 P1（`P1KBCR`） | **全端口**（`P0KBCR`/`P1KBCR`/`P2KBCR`） |
| 端口施密特 | 固定 | **可选阈值**（配置字 `SMTVS`） |
| LVD 响应 | 2ms | **10μs**，且可唤醒 |
| 封装 | TSSOP20/QFN20/QFN16/DFN10/MSOP10 | **QFN20/QFN16/MSOP10** |
