# 记忆待办归集 (memory-todo-harvest)

## 触发场景
用户说类似下面这些话时启用：
- 「把散落在记忆文件里的待办归集一下」
- 「汇总一下各项目记忆里的待办 / 下一步」
- 「更新一下记忆待办」
- 「记忆里有哪些还没做的待办」

## 它做什么
Agent 每天在各项目的 `.workbuddy/memory/` 里写工作日志，日志里散落着「待办 / 下一步 / 未完成」，写完就沉底、没人回头看。
本技能把它们扫出来，推进「生活工作台·记忆待办」云表；**正式看板是生活工作台里的「AI项目管理」模块**（按项目分列，可筛选，拖动卡片排优先级，「项目设置」里改别名 / 勾「纳入副业」；没有勾选——源日志里 `- [x]` 划掉的事，下次同步自动进「已完成」）。勾了「纳入副业」的项目会同时出现在副业 →「AI 赋能项目」页。

## 标准流程（每次跑技能）
1. **扫描预览**：`python harvest.py --scan`（或不起服务的 `harvest.py` 起 127.0.0.1 只读预览页）。
2. **同步上云**：`python <项目>/workbench_build/memory_todo_sync.py`（`--dry-run` 只看差异）。
   - 按「待办ID」diff：新增 / 内容变更 / 源里消失的删除；删除有保护——该项目在本次扫描里仍然存在才删它下面消失的项（D 盘没挂上之类整目录缺失不误删）。
   - **排序、别名、纳入副业是用户数据，同步永不覆盖**（看板上拖动/项目设置产生的）；新增行会继承同项目已有的「纳入副业」。
   - 新增行排序 = 当前最大 + 1（追加到列尾）。
3. 向用户汇报：扫描 N 条 → 新增/更新/删除各多少。

## 识别规则（只认信号，不猜）
1. **待办语义章节**：日志里 `## 待办` / `## 下一步` / `## 未完成` 等标题下的列表项。
2. **checkbox**：`- [ ] xxx` 为待办；`- [x] xxx` 记为已完成（同步进「已完成」列）。
3. **行内待办句**：`**待办**：①…②…③…`，编号自动拆成多条。
4. **笔记句过滤**：章节条目里以 `关键发现：/踩坑：/判定：/结论：/备注：/说明：/注意：` 等开头的是结论不是待办，自动跳过。

## 项目显示名（不用日期目录名）
老工作区目录名是时间戳（形如 `YYYY-MM-DD-HH-MM-SS`），不能当标题用。扫描侧解析优先级：
1. **手工别名** `PROJECT_ALIASES`（代码内，推断自工作区内容，用户可随时改）：网盘整理 / 网盘补传 / Skills 管理 / 闲鱼。
2. **MEMORY.md 首标题提取**：读 `<项目>/.workbuddy/memory/MEMORY.md` 的第一个 `#` 标题，兼容「项目长期笔记：human-atlas（D:\…）」「MEMORY.md · 项目长期笔记（日常集·生活工作台）」「MEMORY.md - Claw 渠道本地记忆（…）」三种写法；命中通用措辞（项目长期笔记/本地记忆/仅此/勿…）的候选丢弃。
3. **目录名兜底**。
4. **用户备注别名最高优先**：在生活工作台「AI项目管理」的「项目设置」面板改，写云表「别名」列，扫描永不覆盖。

同一项目的镜像工作区（C 盘旧位置 + D 盘主目录）会合并成一组，按「同项目 + 同日志文件 + 同行号 + 同文本」去重，出处保留 D 盘新位置。待办 id = 项目|文件|文本（**不含行号**，日志里增删行不会让待办变脸丢排序）。

## 本地预览页（harvest.py）
只读预览：近期未完成（按项目分组 + 进度）/ 历史遗留 · 超 14 天 / 已完成，每条带 signal 标签、日期、文件:行号。没有勾选、没有别名面板——那些都在云表看板上。

```bash
python harvest.py                 # 127.0.0.1 起只读预览服务
python harvest.py --scan          # 只打印汇总
python harvest.py --build 看板.html
python harvest.py --root D:/other-workspace   # 额外扫描根
```

默认扫描根（D 盘主项目在最前，与 C 盘镜像去重时保留新位置出处）：`D:\DATA\AI_DATA\LongTermPro\本地工作台构建`、`~/WorkBuddy`、`~`（个人记忆）。

## 云表结构（生活工作台·记忆待办，9JwdAJ3DtgQe8g4DhalGev）
待办ID / 待办内容 / 自动名 / 别名 / 信号(select) / 章节 / 日期 / 来源文件 / 行号 / 已完成 / 排序 / 扫描时间 / 示例数据 / 纳入副业。
同步脚本只写内容字段 + 扫描时间；排序/别名/纳入副业只在新增时初始化，之后永不覆盖。

## 依赖
- 仅 Python 标准库（`http.server` / `webbrowser` / `json` / `re` / `glob` 等）。
- 不联网、不读取任何外部服务，扫描数据全程不出本机；只有 memory_todo_sync.py 那一步经 agent API 写云表。

## 备注
该技能由用户从「记忆归集待办看板」演示页确认的规格本地构建（当时 marketplace 未上架此技能）。
预览服务仅监听 `127.0.0.1`。

### 踩坑记录
- **模板双括号**：HTML 模板曾按 `.format` 习惯写了 `{{`/`}}`，但 `build_html` 用的是 `.replace`——产物 CSS/JS 全坏，看板白屏。模板里一律用单层括号。
- **Content-Length 必须按字节算**：`_send` 里 `len(body)` 是字符数，body 含中文时 UTF-8 字节数更大，浏览器按 Content-Length 截断（curl 不管这套所以发现不了）。必须 `len(body.encode("utf-8"))`。
- **query 接口字段名是驼峰**：`{"databaseId": …}`，不是 `database_id`；返回的是裸值（日期给带 `T00:00:00Z` 时间部分的完整 ISO 串），写入才是 `{date:…}` 包装——比对时要两边都归一。
- **待办 id 别含行号**：否则日志里增删一行，该待办就被当成新项（排序/别名全丢）。
- **删除要加项目存在性保护**：整目录缺失（D 盘没挂上）时不能把它下面的待办全删了。
- JSON payload 注入前把 `</` 转义成 `<\\/`，防文本里的 `</script>` 提前闭合脚本。
- **TDZ**：模块里调用 `registerView()` 必须放在 `const VIEWS` 声明之后，否则整个 IIFE 启动即崩（白屏）。
