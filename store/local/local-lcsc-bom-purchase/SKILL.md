# 立创商城 BOM 采购加购

> **给改我的人**：成熟度 `v0.x`（完善中）→ 可直接改，改完回报"改了哪个文件、改了什么"即可。
> 本 skill 是**通用**的（跨机器成立）：**别写死**本机磁盘路径、账号、工程名、当次库存与价格 ——
> 库存/价格/料号会变，正文只留方法与判据；具体数字写进项目自己的交付文档。

## 何时用

- 用户给一张元器件清单（截图 / 文本 / CSV），要"在立创商城加购"
- 用户问"某个型号立创搜不到 / 没货，帮我找替代料"
- 需要复核一份采购 BOM 配得对不对

不适用：只要料号不要下单（那只是查询）、PCB 打样/SMT 下单（走 PCB/SMT 流程）。

## 五步流程

1. **清单先落成 CSV 留档**：列 `类型 / 参数型号 / 规格补充 / 封装 / 数量`。
   这类清单常只给"单套用量"、缺封装 —— **先问清再动手**，否则后面全批量返工。
2. **BOM 智能云表**：`bom.szlcsc.com` → 新建 → "手动输入配单"，按 `型号 封装 数量` 逐行粘贴 → 自动匹配。
3. **读底部统计**，这是唯一可信的进度口径：
   `共 N 行 / 完全匹配 A / 待确认 B / 无法匹配 C`，**A+B+C 必须等于 N**。对不上就是还有行没处理完。
4. **分三批处理**：
   - **完全匹配** → 勾选后一次性"加入购物车"。**只点一次**：重复点会让数量翻倍。
   - **待确认** → 逐条核对（见坑 ②），确认后到搜索页按料号单件加购
   - **无法匹配** → 搜索页按型号/参数找料单件加购（见坑 ①）
5. **购物车核对**：新增行数 = 购物车里"已选中/新加"的种数；总数 = 原有 + 新增。
   `共 N 种 / 现货 X / 订货 Y` 三者交叉验证。**应付金额随勾选变化，不能当固定结论汇报。**

## 三个必踩的坑

### ① 型号搜不到，先怀疑抄错

清单是人手抄的，形近字是重灾区：`O↔P`、`M↔N`、`0↔O`、`I↔1`、`l↔1`、`S↔5`。

- **按丝印反查**：很多芯片丝印只是型号的后半截（丝印 `84052` → 型号 `PL84052`）
- **按参数 + 封装反查**：用"功能类型 + 封装 + 电压/电流"在商城筛，再比对 datasheet
- 结论是"立创没有这个型号"之前，上面两步都做过再下

### ② "待确认"行的推荐料号不可信

系统只按封装/参数相似度推，**可能配到完全不同的品类**——见过把直插电解配成贴片钽电容、配成压力传感器的。
所以 `待确认` 行**必须逐条看品类/封装对不对**：宁可不加，也不要错加一件几百块的怪料。

### ③ "替代料"的相似度 ≠ 可替换

商品行里的 `替代料(N)` 按钮会给"相似度 %"和"贴装相同/封装相同"标签，**但它不校验拓扑与电气**：

| 差异 | 它会照给高分吗 |
|---|---|
| 降压 ↔ 升降压（2 开关 ↔ 4 开关） | 会 |
| 5A ↔ 2A | 会 |
| 输入 3V 起 ↔ 12V 起 | 会 |

替换前必须自己核：**拓扑、输入/输出电压范围、输出电流、引脚定义、封装尺寸**。

## 浏览器自动化要点

- 搜索页 URL 可直接跳：`https://so.szlcsc.com/global.html?k=<URL 编码关键词>`
  （中文与空格必须 percent-encode，否则参数校验不过）
- **点输入框 → 输入 → 点按钮之间必须重新取一次可见 DOM**：输入动作会让之前的 node_id 变 stale。
- **别用坐标点击**：截图分辨率与工具坐标空间常常不一致，按截图读数点会全部落空。只用 DOM node_id。
- **"购买数量"框可能写不进去**：需订货的商品页尤其明显（填完被页面重渲染清空，按钮点了也不产生购物车条目）。
  遇到**别硬磕** —— 把"链接 + 填多少 + 点哪个按钮"写进交付文档，让用户点一下。
- 标签页可能被用户关掉（`tabs_list` 变空）→ 重开一个，**tab_id 会重置**，别沿用旧 id。
- 经验：现货商品页的数量框通常可写；订货页、购物车底栏的"编号+数量→添加"常写不进。

## 交付物

一份结果清单（Markdown），至少含：

1. 购物车总数与本次新增行数（含现货/订货拆分）
2. 逐项**实选**料号表：清单项 / 实选型号 / 品牌·封装 / 料号 / 数量 / 单价
3. 没买到的项 + 原因（无型号 / 无库存 / 订货）
4. 与清单**不一致**的地方（封装、耐压、材质、脚数）
5. 需要用户**手动完成**的步骤（订货页那种）

## 顺带产出（可选）

把"实选料号"回填到 CSV，形成可复用的采购档案；型号抄错的项在 CSV 里保留原始写法并注明真实型号，
下次同一份清单再来就不用重查。
