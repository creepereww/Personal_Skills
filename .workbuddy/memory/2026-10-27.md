**★ 踩坑：`Get-GitExe` 在本机返回两个路径**
- 现象：`sync.ps1` 第 29 行报「'D:\Git\mingw64\bin\git.exe D:\Git\cmd\git.exe' 不是可识别的 cmdlet」
- 根因：本机 PATH 里 git 出现两次（`D:\Git\mingw64\bin` 与 `D:\Git\cmd`），
  `Get-Command git -CommandType Application` 返回**数组**，而 `_common.ps1` 里 `return $cmd.Source`
  被 PowerShell 展开成空格拼接的字符串，`& $git` 自然找不到这个「命令名」
- 修法：`@(Get-Command ...)` 包一层数组后取 `[0].Source`；已加注释说明原因
- 影响面：`link.ps1` / `sync.ps1` / `sync-preferences.ps1` 都走这个函数，修一处全好
- 教训：**「装了就会进 PATH」成立，但没保证只进一次**（多套 Git 的各子目录都会写 PATH），
  探测函数一律按「可能返回多个」写
