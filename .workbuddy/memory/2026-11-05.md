## 追问：新机器没有 wsl2win / oc-skills，要不要同步？

用户问得对 —— 新机器上这两条命令确实不存在。结论：**都不进仓库**。

理由：wsl2win 是通用 WSL 工具、links.conf 混着 PXD-YS56 等跨项目条目，属 dotfiles 范畴；搬进
skills 仓库会带本机绝对路径（C:/Users/cgw06/...），换机即失效。真正的缺口是「通用 skill 里没有
自举接法」—— 原知识全在 machine 档（换机按主机名不挂，新机器读不到）。

补法：`local-skills-hub` v0.19 新增「视图模式」节 —— view_dir 语义 + 不依赖任何个人工具的自举命令
（先 link.ps1 建视图，再 WSL 内 `cd /mnt/c/Users/<你>/.skills && ln -s "$PWD/_active/opencode"
~/.config/opencode/skills`，$PWD 免硬编码用户名），并写明 ln -s 遇真目录的坑、需新开会话生效。
machine 档 v0.13 补一句「wsl2win/links.conf 本机设施、不随行」。
