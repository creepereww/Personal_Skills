## 环境坑 2：PortableGit 升级 1.2.0 → 1.3.0，写死的 GCM 路径失效

WorkBuddy 升级后仓库 `.git/config` 里写死的
`.../PortableGit/versions/1.2.0/mingw64/bin/git-credential-manager` 不存在了 →
push 报 `could not read Username`。**修法：改用助手名 `manager`（PATH 解析，版本无关）**：
```bash
git config --local --replace-all credential.helper ""
git config --local --add credential.helper manager
```
